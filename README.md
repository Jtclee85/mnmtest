# 문화유산 학습자료 비교 평가

초등학생용 문화유산 설명 자료와 질문 응답의 A/B 비교 평가 설문입니다.
빌드 과정이 없는 정적 HTML 한 파일로, GitHub Pages에서 바로 서비스됩니다.

## 구성

| 파일 | 설명 |
| --- | --- |
| `index.html` | 설문 전체 (마크업 · 스타일 · 스크립트 · 자료 본문 포함) |

## 설문 흐름

1. **설문 안내** — 응답자 유형(교사 / 예비교사 / 학생 / 기타), 지도 학년 선택
2. **자료 비교** — 문화유산 자료 A와 B를 5개 문항으로 각각 1~5점 평가
3. **응답 비교** — 같은 질문에 대한 두 응답을 5개 문항으로 각각 평가하고, 종합 선택과 자유 의견 작성

## 응답 저장

제출된 응답은 Google Apps Script 웹앱 엔드포인트로 POST되어 스프레드시트에 기록됩니다.
전송 실패에 대비해 브라우저 `localStorage`에도 함께 저장되며, 완료 화면에서 JSON 백업 파일을 내려받을 수 있습니다.

응답 JSON은 `schemaVersion`, `surveyId`, `submissionId`, 응답자 정보, 문항별 A/B 점수,
종합 선택, 자유 의견을 담습니다. 이름이나 연락처 등 개인 식별 정보는 수집하지 않습니다.

### 엔드포인트 교체

`index.html`의 `SHEETS_ENDPOINT` 상수를 새 Apps Script 배포 URL로 바꾸면 됩니다.
Apps Script 웹앱은 **액세스 권한을 "모든 사용자"** 로 배포해야 익명 응답이 기록됩니다.

## 로컬 실행

```bash
python3 -m http.server 8000
```

브라우저에서 `http://localhost:8000` 을 엽니다.
